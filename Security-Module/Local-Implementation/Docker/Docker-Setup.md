# Docker Setup

## Purpose

Docker was installed to create a containerized environment for performing vulnerability scanning using Trivy.

## Software

- Docker Desktop
- Windows 11

## Installation Steps

1. Download Docker Desktop.
2. Install Docker Desktop.
3. Restart the system.
4. Start Docker Desktop.
5. Verify installation.

## Verification

```bash
docker --version
docker compose version
docker info
```

## Result

Docker Desktop was installed successfully and is ready for container-based security scanning.
